# HD1910 · 823 g 双脚支撑蹲起

从随机初始化训练 3,000 轮，4096 个并行环境。使用轮滑式收腿姿态作为深蹲目标，保留 HD1910 的双脚接地和 Observer 机械限位。沿用 SitStand 指令，第一维 0 表示站立，1 表示下蹲。14 个关节的目标角（rad）、躯干根部目标高度（m）见 `target.json`。

在仓库根目录、项目的 Linux CUDA 训练环境执行：

```sh
PYTHONPATH=src python scripts/server/train_crouch_823g.py --output logs/crouch823
```

推理文件为 `policy.onnx`，完整 PPO 检查点为 `model_2999.pt`。各部件的配重与 823 g 行走模型一致。训练以双脚触地作为姿态奖励条件，静止奖励提高到基础值的 1.5 倍，关闭独立头部指令训练。

## 评估

7.4 V 名义仿真，每组 16 个环境，每段指令 6 秒，连续四段。每段最后 2 秒至少 95% 的帧需同时满足倾角、目标高度和平均关节误差要求，蹲姿另要求双脚触地。结果见 `results.json`。

| 工况 | 全程达标 | 未倒 |
|---|---:|---:|
| 站姿起步，交替蹲起 | 16/16 | 16/16 |
| 蹲姿起步，交替站蹲 | 14/16 | 16/16 |
| 保持站立 | 16/16 | 16/16 |
| 保持蹲姿 | 16/16 | 16/16 |

站姿起步时，前三段末段的根部高度中位数依次为 11.83、5.99、11.72 cm，深蹲目标为 5.88 cm。实物待测。
