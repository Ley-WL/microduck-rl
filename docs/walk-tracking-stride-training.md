# 行走速度、转向和步幅微调（2026-10-15）

用户要求继续微调输入/实际速度与转向的偏差，并优先更大步幅、减少小碎步。本轮独立 `walk-tracking-stride-v1-20261015`，从当前实机原行走 ONNX 恢复 actor，不使用已拒绝的停止微调候选。HD1910/当前 STL/kissqy 标称物理/50Hz/现有动作与指令滤波及 PD 保持，训练物理并非硬件辨识结果。

命令均匀覆盖 vx={−.2,−.1,0,.1,.2} m/s × yaw={−.6,0,.6} rad/s，包含原地转向、静止及两个方向；12秒前走/停止/反向/停止课程，24秒回合。线速度跟踪权重5、std .12，角速度权重4、std .35；增加 .35 秒平均速度/侧滑/偏航误差成本。停止成本保留，不依靠输入倍率掩盖跟踪误差。

步幅采用脚离地到落地的沿命令方向位移，完整摆动、单脚交替、抬脚和侧向误差共同约束。距离奖励在目标前单调增加，目标为速度×.55秒（.2m/s时11cm），不是无限大；按滞空时间加权避免靠高频小碎步累计收益。保留失败、关节和接触约束，实际有效步幅、频率和前进速度分别报告。

新 critic/空 Adam，actor归一化冻结；固定LR3e-6、std初始.05；每个优化步在同一Adam更新前加入原actor的on-policy L2保留损失（权重10），组合梯度再次裁剪。它是软约束，不保证旧行为完全保留。先配置测试、64×40执行合同核验、64×5试训/正规ONNX导出，再独立1024×50/Adam400，保存每10轮检查点，不自动追加轮次。

筛选：15种命令×4初态×2种新seed，原/候选各120例，每例24秒且跌倒后永久判失败。分两个行走方向统计 body-forward 速度、yaw、侧滑、停止残速及脚步距离/次数，禁止用水平总速代替前进速度。初始物理状态逐值配对；不声称所有随机化序列位级配对。至少56/60配对存活、无丢原成功、各方向误差/停止不明显退化，同时总体vx/yaw MAE均改善≥10%且有效步幅增加≥10%，才继续两个未用seed的独立回归；这些是预先设定的小样本筛选门，不是实机验收。未通过不部署。
