1. 拉长折扣。训练gamma=.99，名义有效尺度约2秒，而最低速度周期平均达到4秒。但在+.035前进起点，候选相对原版的记录折扣回报差，在.99为−.109，改.997反而+1.185。后期停止好处更重，不支持仅增加gamma。这里只是有限30秒记录回报，无bootstrap，不能称新critic准备度。
